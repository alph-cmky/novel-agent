# Novel Agent

An open-source multi-Agent novel writing framework powered by LangGraph.

## How to Use

1. **Create a project**: type `new MyNovel`
2. **Select your project**: type `select <project_id>`
3. **Write a chapter**: type `write 1 主角穿越到异世界，发现自己拥有系统`

## Pipeline

Orchestrator → Writer → Editor → Continuity → Worldbuilding

Each chapter goes through 5 specialized AI agents working together.
